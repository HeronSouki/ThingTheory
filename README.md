# How Long Would Greg Last? (rendered video)

This branch only holds the finished render, so the code branch stays small.

**[Download greg-biomes-1080p.mp4](greg-biomes-1080p.mp4)**: open it, then use the download button (↓ "Download raw file").

- 1920×1080, 30 fps, 9:56, H.264 + AAC (narration + sound effects)
- Compressed to fit GitHub's 100 MB file limit; visually very close to the master render

The animation code lives on the `claude/kind-brahmagupta-p55xwf` branch. To produce the
uncompressed master (~270 MB) yourself, run `npm install && node render/render.js` there.

To remove this file from the repo later, delete the `video-render` branch.
